# Google 主持语音制作与换词说明

## 当前状态

全套 19 段主持语音已生成并由你确认试听效果，包括一号女巫、二号女巫的独立录音。

- 制作脚本：`outputs/生成老婆谷歌嗲音.py`
- 台词配置：`outputs/谷歌嗲音台词配置.json`
- 游戏使用的音频：`audio/god/`
- 本机成品副本：`outputs/谷歌嗲音全套成品/`
- 本机原版备份：`outputs/旧版语音备份/`

## 密钥与声音编号

脚本可以读取本机的 `~/.config/gemini/api_key`，不用再把密钥写进命令或聊天。这个文件通过访问权限限制其他普通账号读取，不是额外加密的保险箱；不要分享或提交它。

声音编号保存在本机配置目录及 `outputs/.google_voice_id.txt`。这两个位置与参考录音、试听、中间成品和备份都不应上传到代码仓库。网页发布仅需要游戏目录中的成品 MP3，不需要 API Key，也不需要玩家连接 Google。

若以后更换声音，必须获得声音拥有者对克隆及用途的同意，按 Google 当前页面完成验证。多个克隆声音存在时，请明确用 `--voice` 指定，避免脚本默认选择最新音色。

## 以后只换一两句话

先改 `outputs/谷歌嗲音台词配置.json` 中对应条目的 `text`。文件名不能随意修改，例如 `wolfAction` 对应狼人播报，`witchAction_1` 对应一号女巫。

在项目目录运行下面的命令，仅重新生成指定两句，不立即替换游戏：

```bash
python3 outputs/生成老婆谷歌嗲音.py --only wolfAction,witchAction
```

试听满意后，再进行本地安装。注意：下面命令会再次调用 Google 生成这两句，可能再次计费：

```bash
python3 outputs/生成老婆谷歌嗲音.py --only wolfAction,witchAction --install
```

也可以直接告诉我需要修改哪句话，由我检查现有成品后处理，避免重复生成。

## 重新生成试听或全套

只生成三句试听：

```bash
python3 outputs/生成老婆谷歌嗲音.py --sample
```

重新生成全部 19 句并备份、安装到本地游戏：

```bash
python3 outputs/生成老婆谷歌嗲音.py --all --install
```

调用 Google 可能收费，以账号计费页面为准。这些命令不会自动提交 Git 或发布网站；发布仍需单独确认。

## 风格与时长

配置保留三种语气预设：`sweet_gentle`、`coquettish_whisper`、`sultry_tease`。当前使用 `coquettish_whisper`。调慢语速、增加停顿可能使语音变长；字符数量不能保证实际时长。

脚本会输出每句时长，但超过提示阈值时只警告，不会自动阻止安装。换词后应检查语音与游戏切换时间是否匹配，尤其是开场、入夜、无人操作等待和天亮过渡，不能仅凭脚本执行成功判断。

输出统一为 44.1kHz 单声道 MP3，并做响度处理。把低采样率声音转换为 44.1kHz 不会恢复原本不存在的高频细节，也不能单凭参数判断更好听。
